# Generated data and realistic demos

Verify input → generated data separately from generated data → pixels. Freeze sufficient read-only input, hashes, parameters and extraction source. Use original native generation for native generation claims; adapters must expose unsupported queries. Repeat generation independently, compare exact bytes, then compare renderer pixels. Retain before/after source hashes without modifying saves.

Map uses 342 frozen chunks, original MapItem.update and original MapRenderer. `tests/reference/map/demo-world/` retains inputs, palette, generation reports and captures. `preview/demos/map-world-data.ts` must embed that exact palette. The local evidence checker checks the committed chain; it does not regenerate native output.

For remote profiles, freeze texture bytes and model metadata. Inference is a web fallback, distinct from authoritative metadata. Verify replacement and explicit overrides separately.

Realistic demos must exercise connected state: selection, scoreboard awards, replacement and other controls update the visible result. Integration behavior is separate from native pixel evidence.
