## Usage

Import `AdvancementTree` and `AdvancementNode` from `@/components/ui/advancement-tree`. Pass `nodes` with unique `id`, `title`, finite grid coordinates `x`/`y`, and an optional `parentId`. Missing parents, duplicate IDs and cycles throw. Coordinates map to 28 by 27 logical-pixel grid steps; the default viewport is 234 by 113 logical pixels.

The primary example owns `selectedId` through `onSelectedIdChange`. Use `defaultSelectedId` for internal selection. `pan`/`onPanChange` and `defaultPan` control the view independently.

## Composition

`kind` chooses `task`, `goal` or `challenge`; `completed` changes its frame. Hidden nodes become visible when completed. Custom `icon` content is caller-owned. Selection does not complete a node or mutate your graph.

The root is a focusable group. Drag to pan; root arrows pan by 16 logical pixels and Home recenters. On node buttons, arrows traverse input order. Nodes expose `aria-pressed`; tooltip content is supplied by each node's title and description. The component includes its tooltip provider.
