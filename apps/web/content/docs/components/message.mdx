## Usage

Place MessageContent inside Message. Scalar content automatically prefixes the supplied author, so pass only the message body. `kind="system"` uses yellow system text; align supports start/end.

## Composition

MessageGroup groups rows but does not supply scale context. Set scale on each Message or inherit it from MessageScroller. MessageAvatar, Header and Footer support additional arrangements; rich children are preserved rather than treated as a plain chat string.

## Interaction and limits

Keep stable message identifiers in a scrolling conversation and choose live-region behavior for your application. Captured coverage concerns fixed chat foreground rows, colors, widths and glyph sets; avatar arrangements, reactions, fading and arbitrary rich content are outside that native scope.

See the [upstream API](https://ui.shadcn.com/docs/components/message) for the underlying part and event contracts.
