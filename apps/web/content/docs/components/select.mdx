## Usage

Import `Select`, `SelectTrigger`, `SelectValue`, `SelectContent` and `SelectItem` from `@/components/ui/select`. Supply Root `items` with matching value/label pairs so `SelectValue` resolves the selected label. Use `value`/`onValueChange(next, details)` or `defaultValue`.

## Composition

Place `SelectValue` inside the accessible trigger and items inside the portaled `SelectContent`. The example uses `alignItemWithTrigger={false}` and `sideOffset={4}` at scale 2. `SelectGroup`, `SelectLabel` and `SelectSeparator` organize longer menus; scroll buttons are available for constrained popup height. [Native Select](/docs/components/native-select) offers a real HTML select when platform popup behavior is preferable.

## API and accessibility

The trigger supports only `size="default"` and long text scrolls. The default popup aligns its selected item with the trigger; content defaults to bottom/start with collision padding 10. Cycle-button artwork and native language-list constituents are reused in a web dropdown composition. No chevron/checkmark variant is promised by this wrapper. Popup lifetime follows the Select primitive’s default behavior.

See the [underlying API](https://base-ui.com/react/components/select) for shared semantics.
