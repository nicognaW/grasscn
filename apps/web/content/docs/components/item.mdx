## Usage

The example uses a passive Item with a separate Open button and visible activation count. Use `render={<a href="..." />}` or a button when the whole row should be interactive; a passive div does not become a button by itself.

## Composition

ItemMedia with no children displays the packaged world thumbnail. ItemContent supplies clip measurements to Title and Description. ItemGroup shares scale with rows, ItemSeparator divides them, and Header/Footer/Actions support passive row compositions. Only default size and variant are supported.

## Interaction and limits

Avoid putting nested interactive controls inside a whole-row anchor. Use a passive Item with ItemActions for separate actions. Native row coverage is limited to compatible-world reference contents/states; arbitrary rich media, custom layouts and incompatible-world states need separate evidence.

See the [upstream API](https://ui.shadcn.com/docs/components/item) for the underlying part and event contracts.
