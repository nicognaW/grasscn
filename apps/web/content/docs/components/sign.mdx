## Usage

Import `Sign` or `HangingSign` from `@/components/ui/sign`. Supply up to four strings in `lines`; a fifth line throws. The defaults are `wood="oak"`, `color="#000000"` and `glowing={false}`. Standing signs measure 120 by 110 logical pixels; hanging signs measure 120 by 74.

The named example uses `HangingSign` from the same installed module. Both examples carry their complete line data inline.

## Composition

`wood` is one of oak, spruce, birch, jungle, acacia, dark_oak, mangrove, cherry, bamboo, crimson, warped or pale_oak. `color` must be a six-digit hex color. Non-glowing ink darkens each supplied channel to 40 percent; glowing ink uses the supplied color.

These are display groups, not editable text fields. Own editing in separate controls, then pass updated `lines`. The default accessible name joins the lines; an explicit `aria-label` names the board, while hidden text retains the complete lines. Texture/font painting is asynchronous.
