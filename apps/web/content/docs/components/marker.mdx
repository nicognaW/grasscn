## Usage

A scalar Marker child is automatically wrapped in MarkerContent. variant supports default, separator and border; separatorEdge defaults to header. MarkerContent accepts align and logical maxWidth. MarkerIcon is decorative and aria-hidden, so keep the notice text meaningful without it.

## Composition

The bordered notice below combines MarkerIcon and MarkerContent. Separator/border line and label constituents retain their declared cases; custom icons, links and notice arrangements are web compositions, without a native Marker widget claim.
