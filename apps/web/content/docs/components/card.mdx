## Usage

The example controls the installed Input and saves through Button. CardTitle is a div, so supply an actual heading when the card starts a document section. CardAction is available for a header-side action; keep editable content in CardContent and actions in CardFooter.

## Composition

Install Input and Button as separate items when reproducing this composition. CardHeader, CardContent and CardFooter inherit Card scale; arbitrary section layout and rich content are web adaptations around the popup surface.
