## Usage

Import `Button` from your installed `components/ui/button` module. The primary example uses scale 2: its default 200 by 20 logical pixels render at 400 by 40 browser pixels.

Activate a button to hear the original Minecraft click.

## Composition

Keep a visible label for the default button. Use the retained playground to change the label and width, activate the button and compare its disabled state.
