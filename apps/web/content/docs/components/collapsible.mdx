## Usage

open/onOpenChange control this example. Without them the Base UI root owns disclosure state. CollapsibleTrigger is a native-skinned Button; CollapsibleContent defaults to align="left" and wrap=true. maxWidth is a logical text width, independent of the outer container width.

## Composition

Scalar content uses the measured disclosure text path; rich children render separately. Compose links or fields inside Content as ordinary interactive children and let Trigger own disclosure. Open/closed whole-panel geometry is a web adaptation, while the Button constituent retains its declared evidence.
