## Usage

Root defaults to `swipeDirection="down"`, which opens the bottom-side layout. Use up, left or right for a different swipe direction. The wrapper does not expose a Radix/Vaul `direction` prop.

## Composition

Content owns Portal, Overlay and Viewport. Compose Header, Title, Description, Footer and Close inside it. The example turns off the automatic close and supplies `DrawerClose` with Done. Root provides the inherited integer scale.

## Interaction and limits

DrawerClose defaults to Done. Drag, snap and focus behavior come from Base UI Drawer. The edge arrangement and gestures are web adaptations; only the declared PopupScreen panel and label constituents have native pixel coverage.

See the [upstream API](https://base-ui.com/react/components/drawer) for the underlying part and event contracts.
