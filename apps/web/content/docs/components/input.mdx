## Usage

Import `Input` from `@/components/ui/input`. The example uses `value` and `onChange(event)`; use `defaultValue` for uncontrolled editing. It defaults to `type="text"`, `spellCheck={false}` and `autoCorrect="off"`, preserving explicit overrides.

## Composition

Use a [Label](/docs/components/label) or `aria-label` on the real input. `name`, `required`, `maxLength`, `readOnly`, `disabled` and the imperative ref retain native input behavior. Group supporting text and validation with [Field](/docs/components/field), or actions with [Input Group](/docs/components/input-group).

## API and accessibility

The default geometry is 200 by 20 logical pixels at scale 2. Border, glyphs, caret and selection use the painter and delivered font resources. Password/special input types, unsupported glyphs and RTL may use browser text rendering; native pixel coverage is limited to recorded glyphs and conditions.

See the [underlying API](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/input) for shared semantics.
