## Usage

The installed generic `DataTable` accepts columns, data and scale. Build columns with `createColumnHelper<DataTableFeatures, World>()` and `helper.columns`. Install both data-table.tsx and data-table-features.tsx; the latter defines the actual feature set.

## Composition

The full world-browser example uses `useTable({features,columns,data})`, `table.FlexRender`, table.state and real column/pagination methods. It provides filtering, sorting, column visibility, page navigation and keyboard row selection. These controls are composed in the example rather than automatic DataTable props.

## Interaction and limits

The empty state comes from the block when no rows remain. TanStack 8 useReactTable/getCoreRowModel examples do not match this installed version. Table layout, engine state and controls are web adaptations; native claims apply to the recorded painted constituents.

See the [upstream API](https://tanstack.com/table/latest/docs/introduction) for the underlying part and event contracts.
