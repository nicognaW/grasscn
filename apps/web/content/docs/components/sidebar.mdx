## Usage

SidebarProvider is required; useSidebar throws outside it. The primary example explicitly uses collapsible="none" to remain inside its preview. The actual Sidebar default is offcanvas, side="left", variant="sidebar"; icon and none are also supported collapse modes. Other visual variants throw.

## Composition

The responsive example below uses the actual default offcanvas mode, SidebarTrigger and controlled open/onOpenChange. At widths up to 767px a separate openMobile state drives Sheet; desktop open does not control mobile visibility. Control/Command+B toggles globally. The provider writes sidebar_state for seven days but never reads it: pass your chosen defaultOpen explicitly to restore a stored preference.
