## Usage

A scalar child selects the centered native empty-list path; size the root to position it. Structured children select the Header/Title/Description/Content composition instead. EmptyMedia supports only the default variant. The Create world example keeps its action and disabled state in the caller.

## Composition

The structured example adds EmptyHeader, EmptyTitle, EmptyDescription and EmptyContent around a separately installed Button. It deliberately differs from scalar centered empty-list geometry; the complete empty screen is a web composition.
