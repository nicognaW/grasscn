## Usage

Give ScrollArea a bounded width and height. viewportRef addresses the scrollable div, not the root. viewportProps carries its label and onScroll handler. type="auto" and a vertical ScrollBar are the supported modes; horizontal or alternate scrollbar modes throw. disabled stops scrolling without disabling buttons inside.

## Composition

Put interactive rows inside the viewport and move scrollTop through viewportRef for application navigation. ScrollBar is separately exported for vertical composition. The retained playground demonstrates Top/Middle/Bottom, row selection and the disabled-scrolling state.
