## Usage

Wrap triggers in `TooltipProvider`. Use `TooltipTrigger render={<Button />}` to keep the real button semantics; pass the same integer scale to the Button and TooltipContent because the root has no scale context.

## Composition

`TooltipContent` already creates its portal and positioner. It defaults to top/center, sideOffset 0 and a maximum logical text width of 170. Scalar text, including explicit newline strings, uses the painted tooltip text; rich children take the custom-content path.

## Interaction and limits

Provider delay defaults to 0. Hover or focus the trigger; Escape dismisses the tooltip. Keep the trigger independently named. The existing native coverage covers fixed ASCII layouts and solid backdrops; rich content and arbitrary image backdrops do not inherit that claim.

See the [upstream API](https://base-ui.com/react/components/tooltip) for the underlying part and event contracts.
