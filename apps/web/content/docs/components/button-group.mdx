## Usage

ButtonGroup defaults to horizontal orientation and supplies role="group". Give the group a purpose-specific accessible name. ButtonGroupText uses the inherited scale with optional logical maxWidth and align. ButtonGroupSeparator defaults to vertical, unlike the standalone Separator component.

## Composition

Use ButtonGroupText for the current action result and separators only between related actions. Vertical groups are supported layouts, but a rotated vertical separator is a web adaptation. Install Button alongside the group rather than expecting the group export to create action buttons.
