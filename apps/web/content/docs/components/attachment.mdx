## Usage

The example reports preview activations and removes/restores the attachment in local state. Supply an aria-label to AttachmentTrigger and each icon-only AttachmentAction. The component does not upload or process files.

## Composition

Compose Media, Content, Title and Description, then Trigger and Actions. Empty Media uses the packaged world thumbnail. Root defaults to state done, horizontal orientation, scale 2 and default size. selected and disabled are independent props; disabled cancels attachment interactions.

## Interaction and limits

States idle/uploading/processing/error/done describe presentation only. Your application owns upload progress, file permissions and backend effects. Custom media and attachment action layout are web compositions; the copied example requires no external thumbnail server.

See [Item](/docs/components/item) for the related world-row composition and [Message](/docs/components/message) for chat integration.
