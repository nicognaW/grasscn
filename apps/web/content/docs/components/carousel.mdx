## Usage

Give Carousel an accessible name, place Content and Item inside it, then Previous and Next within the same provider. The example has three world cards; arrows retain default accessible Previous/Next slide names.

## Composition

Root accepts opts, plugins and setApi and defaults to horizontal orientation. It derives the Embla axis from orientation. `useCarousel` and all parts require the provider. Arrow variant and size support default only; Card is a separately installed composition.

## Interaction and limits

Arrow keys respect vertical orientation and RTL and avoid text-edit targets. Dragging and slide state are web adaptations; native pixel scope applies to arrow constituents rather than the whole carousel. The example includes its own arrow clearance and layout.

See the [upstream API](https://www.embla-carousel.com/) for the underlying part and event contracts.
