## Usage

Breadcrumb provides a nav labelled Breadcrumb and BreadcrumbList an ordered list. BreadcrumbLink supports render composition for a router anchor. BreadcrumbPage is an aria-disabled current-page span with role="link". It supplies location semantics without an active destination.

## Composition

Keep separators outside BreadcrumbItem. BreadcrumbEllipsis is presentation-only and its More text is hidden too; use a labelled Button or menu trigger for interactive overflow. The ordered path and focus ring are web adaptations around native label glyphs.
