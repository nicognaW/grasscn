## Usage

Install `message`, then import Bubble parts from components/ui/bubble. `from="user"` and `from="assistant"` derive Player and Assistant authors unless author is supplied. Scalar Content prefixes that author automatically.

## Composition

BubbleGroup and Bubble inherit MessageScale, defaulting to 2. Bubble supports align start/end and the default backdrop variant only. `BubbleReactions` defaults to bottom/end and accepts actual interactive children. The example toggles a real reaction button state.

## Interaction and limits

System bubbles use yellow text. Bubble grouping and reaction placement are web compositions over chat rendering; no separate vanilla bubble widget or independent installation item is claimed. Related Message and Message Scroller pages share the same complete installation payload.

See the [upstream API](https://ui.shadcn.com/docs/components/message) for the underlying part and event contracts.
