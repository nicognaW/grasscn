## Usage

Mount one Toaster in your application, then call the exported `toast(title,{description})`. The primary example contains its own host for copying into a standalone page. Avoid a second host if your application already mounts one. No theme provider or demo portal helper is required.

## Composition

Defaults are position="top-right", offset=0, gap=0, visibleToasts=5, richColors=false and expand=true. Unsupported richColors=true or expand=false throw. Actions, dismiss controls, rich HTML, alternate placement and library timers/swiping are web adaptations beyond the retained native SystemToast frames.
