## Usage

This page previews the installable CodeBlock renderer. The surrounding preview/code switch and source viewers belong to the documentation site. CodeBlockContent defaults to wrap=false, lineNumbers=false and startLine=1. CopyButton needs the exact source value: it never extracts or reconstructs text from rendered children.

## Composition

For syntax highlighting install the delivered useHighlightedCode hook and highlight-code library with Shiki, then render returned lines through CodeBlockLine. Diff variants added/removed/highlighted are shown below. Copy feedback follows the clipboard promise, announces success politely, resets after two seconds and leaves success unset when the clipboard is unavailable or rejects the request. This installed button does not announce a failure; add application feedback if your workflow requires it.
